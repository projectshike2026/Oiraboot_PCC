Platform Architecture

Verified Academic Intelligence

Engineered by Oiraboot (ঐরাবত) • 2026

1. Strict Source Verification

Unlike generic conversational wrappers that make plausible-sounding guesses, every response generated in the Oiraboot Academic Intelligence Suite undergoes server-side verification before reaching the user:

  • Document Studio (Track 1): Answers require verbatim character-for-character citation spans. The server validates each chunk against the source PDF text using exact matching and high-ratio fuzzy string comparison (SequenceMatcher ≥ 0.85). If zero citations verify, the engine strictly outputs "Not found in the document".
  • Admissions Desk (Track 2): Every fact is verified against official institutional records (data/admission.txt). All numerical quantities (tuition fees, credit counts, dates, minimum GPAs) are verified against the document's cached number set. If ungrounded or absent, the model strictly reverts to official admission office referral contacts.
  • Scholarship Atlas (Track 3): Eligibility matching is verified directly in code against live CSV records. AI-generated fit summaries fall back to strict template rationales whenever the model is unavailable.

2. Hybrid BM25 & Full-Context RAG Architecture

For short lecture documents (≤ 48,000 characters), the engine passes all page-bounded chunks to ensure zero retrieval misses. For larger materials, an in-memory pure Python implementation of BM25 selects the most contextually relevant excerpts across pages, accounting for prior conversation turns to handle follow-up queries naturally.

3. Bilingual English & Bangla Fidelity

Built natively for students in Bangladesh, the entire UI chrome, error handling, question prompts, and AI reasoning streams seamlessly between English and Bangla. Language detection automatically detects Bengali script input to deliver native Bangla answers with identical source proofs.

4. Modular Studio Ecosystem

Oiraboot separates concerns into dedicated workspaces: Document Studio (`/documents`), Admissions Desk (`/admissions`), and Scholarship Atlas (`/scholarships`), unified under an Overview Portal (`/`).
